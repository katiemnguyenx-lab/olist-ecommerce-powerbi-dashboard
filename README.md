# Olist E-Commerce Performance Dashboard

## Project Overview
This project analyses Olist e-commerce marketplace data to understand sales performance, delivery efficiency, customer satisfaction, product category performance, and regional demand.

## Business Problem
The dataset was spread across multiple tables, making it difficult to get a clear view of marketplace performance. The goal was to create an integrated dashboard for business decision-making.

## Tools Used
- Power BI
- Power Query
- Excel
- Data cleaning
- Data modelling
- Dashboard design

## Key Features
- Revenue and order trend analysis
- Product category performance
- Customer orders by region
- Delivery status and delay analysis
- Freight cost and review score analysis

## Key Insights
- Identified top-performing product categories
- Analysed delivery performance and customer satisfaction
- Highlighted regional demand patterns
- Suggested recommendations for logistics and product strategy
